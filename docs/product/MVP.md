# MVP product lock

## Promise

Turn screen time into building time. Level helps a child understand a problem, instruct a machine, predict the outcome, test the result, recognise errors and create something of their own.

## Audience modes

| Mode | Ages | Adaptation |
|---|---:|---|
| Explorer | 6–8 | Short objectives, larger interaction targets, reviewed dialogue and read-aloud support |
| Builder | 9–10 | Visual logic, multi-step missions, explanation and guided creation |
| Creator | 11–12 | Richer language, transfer, system thinking and a later pseudocode/code reveal |

The modes share one universe and one identity. They are not labelled easy, medium or hard.

## Learning loop

Every mission follows the same product rhythm:

**Objective → Predict → Build → Run → Inspect → Fix → Explain → Create**

The first release implements one world exceptionally narrowly: twelve missions, one original build, one boss assessment, a deterministic learning engine and a parent mastery summary.

## Deliberate exclusions

- No public gallery or child-to-child communication.
- No adverts, in-app currency or streak-loss pressure.
- No unrestricted chatbot.
- No arbitrary child- or model-generated code execution.
- No school dashboard before the family experience proves engaging and educationally coherent.
