# Android release checklist

## Product and policy

- [ ] Confirm the declared 6–8 and 9–12 audiences are genuinely supported.
- [ ] Review Google Play Families requirements against every included SDK.
- [ ] Publish a child-appropriate privacy policy and accurate Data safety declaration.
- [ ] Provide parent-accessible account and data deletion routes before remote accounts launch.
- [ ] Confirm there is no behavioural advertising, advertising ID, location or public communication.
- [ ] Complete qualified privacy review and DPIA.

## Build

- [ ] Confirm the current target API requirement at submission time.
- [ ] Generate a signed production AAB from the `production` EAS profile.
- [ ] Verify declared permissions in the final merged Android manifest.
- [ ] Test phone and tablet layouts, portrait and landscape mission use.
- [ ] Test offline restart and progress recovery.

## Accessibility and quality

- [ ] TalkBack traversal and labels.
- [ ] Large text and reduced-reading mode.
- [ ] Colour-independent feedback and contrast.
- [ ] Switch/keyboard access for command tiles.
- [ ] Reduced animation option.
- [ ] Crash, low-memory and interrupted-save recovery.

## Release access

- [ ] Determine whether the Play Console account is personal or an organisation account.
- [ ] If required, complete the current closed-test and production-access process.
- [ ] Review all store screenshots and copy so the child-facing experience matches the declared audience.
