# Secure backend boundary

No backend is required to play the current vertical slice. This directory intentionally remains a boundary until parent ownership, consent, retention and deletion decisions are locked.

The first backend implementation should provide:

- parent authentication and child-profile ownership;
- consent record versioning and revocation;
- versioned missions and reproducible hidden tests;
- structured attempts, mastery state and private project versions;
- export, retention and deletion workflows;
- a model-independent tutor gateway with input minimisation, personal-information protection, structured output validation and reviewed fallbacks;
- operational audit events that do not retain raw voice or full child transcripts by default.

The client must continue to compile command tiles and later Blockly blocks into the safe intermediate representation. Neither the backend nor an AI model may replace deterministic mission pass rules.
